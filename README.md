# QR Code Generator

A modern QR code generator built with React and TypeScript.

## Features
- Generate QR codes from URLs
- Customize QR code colors
- Adjust error correction level
- Download QR codes in PNG, SVG, or PDF format
- Add custom logo to QR codes
- Dark mode support
- QR code history tracking
- Share QR codes via social media
